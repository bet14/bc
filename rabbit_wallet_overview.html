What is Rabby Wallet?

Rabby Wallet is a browser extension wallet designed for Web3 users who want security, simplicity, and control. It's built to protect users from common Web3 risks while making blockchain interactions seamless.

Quick Facts

🌐 Multi-Chain Support

Works with Ethereum, BSC, Polygon, Arbitrum, Optimism, and 50+ other chains

🔐 Non-Custodial

You control your private keys. Rabby never has access to your funds

⚡ Fast & Lightweight

Minimal resource usage, quick transaction processing

🛡️ Risk Detection

Automatically detects and warns about suspicious transactions

💡 Key Insight: Rabby is developed by Defi Labs and is completely open-source, allowing the community to audit and verify its security.

Core Features

1. Transaction Simulation & Risk Detection

Before you sign any transaction, Rabby simulates it to show you exactly what will happen. It detects:

  • Phishing attempts
  • Suspicious token approvals
  • Malicious smart contracts
  • Unusual fund transfers

2. Token Approval Management

See all your token approvals across all chains and revoke them with one click. This prevents hacks from compromised contracts.

3. Multi-Signature Support

Connect hardware wallets (Ledger, Trezor) for enhanced security on high-value transactions.

4. NFT Gallery

View and manage your NFT collection directly in the wallet with beautiful previews.

5. DeFi Dashboard

Monitor your positions, yields, and portfolio performance across multiple protocols.

6. Custom RPC Support

Add custom RPC endpoints for any EVM-compatible chain.

🔄 Batch Transactions

Execute multiple transactions in one go

📊 Portfolio Tracking

Real-time value tracking across all assets

🌙 Dark Mode

Easy on the eyes for extended use

Security Features

Why Rabby is Secure

Rabby implements multiple layers of protection:

✓ Open Source
✓ No Seed Phrase Storage
✓ Local Encryption
✓ Hardware Wallet Support
✓ Transaction Simulation
✓ Regular Audits

Transaction Security Flow

  1. Detection: Rabby analyzes the transaction before you sign
  2. Simulation: Runs the transaction in a sandbox environment
  3. Analysis: Checks for known attack patterns
  4. Warning: Alerts you to any risks found
  5. Control: You decide whether to proceed

How to Get Started

Installation

  1. Visit the Chrome Web Store or Firefox Add-ons
  2. Search for "Rabby Wallet"
  3. Click "Add to Chrome" or "Add to Firefox"
  4. The extension will appear in your browser toolbar

Creating Your First Wallet

  1. Click the Rabby icon in your toolbar
  2. Choose "Create New Wallet"
  3. Write down your 12-word seed phrase (keep it safe!)
  4. Confirm your seed phrase
  5. Set a strong password
  6. You're ready to go!

Importing Existing Wallet

  1. Click "Import Wallet"
  2. Paste your 12 or 24-word seed phrase
  3. Set a password
  4. Your accounts will be restored
⚠️ Important: Never share your seed phrase with anyone. Rabby staff will never ask for it. Anyone with your seed phrase can access all your funds.

Frequently Asked Questions

Is Rabby Wallet free?

Yes, Rabby Wallet is completely free. There are no hidden fees or premium tiers.

Can I use Rabby on mobile?

Currently, Rabby is available as a browser extension (Chrome, Firefox, Edge). Mobile support is in development.

What happens if I lose my seed phrase?

Your funds cannot be recovered without your seed phrase. Store it securely in multiple locations (paper, safe, etc.).

Is my private key stored on Rabby servers?

No. Your private keys are encrypted and stored only on your device. Rabby never has access to them.

Can I connect multiple wallets?

Yes, you can import multiple seed phrases or add hardware wallets to the same extension.

How do I report a security issue?

Contact the Rabby team through their official GitHub or security email. Do not share details publicly.

Which chains does Rabby support?

Rabby supports 50+ EVM-compatible chains including Ethereum, Polygon, Arbitrum, Optimism, BSC, Avalanche, and more.

Can I use Rabby with DeFi protocols?

Yes! Rabby is designed for DeFi users. It works with Uniswap, Aave, Curve, and thousands of other protocols.
